# Campus-Placement-Intelligence-Dashboard
This Power BI dashboard analyzes student placement trends, salary insights, specialization performance, gender distribution, and the impact of work experience on campus placements.

Tools Used:
• Power BI
• Power Query
• DAX
• Data Visualization

Key Insights:
• Placement rate reached 68.84%.
• Marketing & Finance students secured the highest placements.
• Students with work experience showed strong placement outcomes.
• Gender-wise placement distribution was analyzed using interactive filters.

## Requirements

To view and interact with this project, ensure you have:

- Microsoft Power BI Desktop
- Windows 10/11 (recommended)
- Placement_Data_Full_Class.csv dataset

## How to Open

1. Download the repository files.
2. Install Microsoft Power BI Desktop.
3. Open `Placement Analysis.pbix`.
4. If prompted, reconnect the dataset `Placement_Data_Full_Class.csv`.
5. Refresh the data to load the latest visuals.

- `Placement Analysis.pbix` – Power BI dashboard file
